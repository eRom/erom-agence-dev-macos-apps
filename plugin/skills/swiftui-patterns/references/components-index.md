# Components Index

Utiliser ce fichier pour trouver les guides de scene et de composants. Chaque entrée indique quand l'utiliser.

## Références disponibles

- Windowing : `references/windowing.md`, à utiliser pour choisir entre `WindowGroup`, `Window`, `DocumentGroup` ou les API d'ouverture de fenêtre.
- Settings : `references/settings.md`, à utiliser pour les scenes settings dédiées, le stockage de préférences et les points d'entrée settings.
- Commands and menus : `references/commands-menus.md`, à utiliser pour les menu items, raccourcis clavier, actions focused et le routage de commands.
- Split views and inspectors : `references/split-inspectors.md`, à utiliser pour les apps sidebar-detail, les inspectors et les layouts desktop pilotés par la sélection.
- Menu bar extras : `references/menu-bar-extra.md`, à utiliser quand l'app vit principalement dans la menu bar.
